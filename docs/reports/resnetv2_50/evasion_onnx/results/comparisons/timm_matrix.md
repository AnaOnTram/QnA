### linf tolerance note

The attack clamps in float32 and the CSVs store `norm * 255`, so `1/255` in float32 records `linf_255 = 1.0000079` at eps=1 (max observed `linf_255/eps_255` ratio 7.51e-6 across all retained arms). The clamp bound is therefore relative on the 255-scale: `linf_255 <= eps_255*(1+0.0001) + 1e-06`. This reconciles the original validator's absolute +/-1e-6 slack on the normalized norm (the 255-scale relative allowance is far below any real attack-budget violation, and any row outside it is listed with exact values in `validation.checks.linf_budget.examples`).
